# StockFlow frontend

Keep this an Angular standalone, RTL, single-company multi-warehouse client. Preserve the real API contract in docs/API-MAP.md and backend-openapi.snapshot.json. Use Reactive Forms and small services; do not introduce state-management frameworks without a concrete need. Never embed accounts, passwords, database connections or production tokens. Do not fabricate backend endpoints, dashboard statistics or successful deployment. Preserve row versions for If-Match and do not automatically retry stock mutations on network failure. Server permissions and stock rules remain authoritative. Run npm test and npm run build for behavioral changes. Update docs/VERIFICATION.md with actual evidence and limitations. Do not commit or deploy automatically when asked only to prepare source.
